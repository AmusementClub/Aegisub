Miscellaneous functions in Automation 4

This document describes various functions that couldn't be placed in any of
the other Automation 4 documents.

---

Getting the rendered size of a string

This function might later on be part of a full rendering-interface for
creating actual bitmaps of text.

This function does NOT attempt to handle line breaks, automatic line breaking,
fomatting override tags, vector drawings or anything else to that effect.
If you need such functionality, you need to implement it yourself. (For now,
at least.)

function aegisub.text_extents(style, text)

@style (table)
  A "style" class Subtitle Line table.

@text (string)
  The text to calculate the rendered size of.

Returns: 4 values, all numbers.
  1. Width of text in pixels.
  2. Height of text in pixels.
  3. Descent of text in pixels.
  4. External leading of text in pixels.

Getting a read-only visual-guide snapshot

function aegisub.get_visual_guides()

Returns one table. The table is always returned, including when the current
Automation host has no live GUI, visual-guide controller, or video.

The top-level fields are:
  schema_version (number)
    The snapshot schema version. This version is 1.
  available (boolean)
    True when the remaining fields describe a live visual-guide state. False
    means visual-guide data is unavailable in the current host.
  generation (number)
    A monotonically changing state version when available. It can be used to
    avoid processing an unchanged snapshot, but is not a guide ID.
  frame (number)
    The current video frame number, or -1 when unavailable.
  script_resolution (table)
    { width = number, height = number }, using the script PlayRes.
  frame_resolution (table)
    { width = number, height = number }, using source video pixels. This is
    contextual metadata only; guide coordinates are not stored in frame space.
  selected_id (string or nil)
    The currently selected guide ID, when one is selected.
  last_measurement_id (string or nil)
    The most recently created measurement guide ID, when one exists. With only
    measurement guides, this is always guides[#guides].id when the array is
    non-empty.
  guides (array)
    Guides in the same order as the visual-guide overlay is drawn.

When available is false, generation is 0, frame is -1, both resolutions are
{ width = 0, height = 0 }, and guides is an empty array. selected_id and
last_measurement_id are nil.

Every guide has id, kind, coordinate_space, first, second, delta_x, delta_y,
distance, angle_degrees, shear_x, shear_y, angle_horizontal_degrees,
and angle_vertical_degrees.

kind is currently always "measurement_segment". coordinate_space is currently
always "script" and identifies the units used by all coordinates (script
PlayRes pixels). It is never a canvas, DPI, OpenGL, Skia, or source-frame
coordinate system.

Scripts should tolerate unknown future kind and coordinate_space values.

distance is non-negative. angle_degrees uses atan2(delta_y, delta_x) in the
range [-180, 180]; because the video and ASS y axis points down, positive
angles appear clockwise on screen. Values are raw doubles and are not rounded
to match an overlay label.

shear_x is delta_x/delta_y (0.0 when delta_y is 0), the horizontal shear
coefficient matching the \fax tag. shear_y is delta_y/delta_x (0.0 when
delta_x is 0), matching \fay. angle_horizontal_degrees equals angle_degrees
(the angle to the X axis). angle_vertical_degrees is the angle to the Y axis,
atan2(delta_x, delta_y) in [-180, 180]. All four are raw doubles; the on-screen
overlay renders them as ASCII ("deg" suffix, "-" for an axis-parallel shear).

The returned table is a value snapshot. It does not change after later guide
edits, and the API cannot create, modify, delete, draw, or receive mouse events
for guides. Scripts should read this API on demand rather than busy-polling it.

Getting the subtitle edit box cursor

function aegisub.get_edit_box_cursor()

Returns the current cursor/selection position in the main subtitle text edit
box as a half-open range [start, stop) of 0-based character offsets.

Returns: 2 values.
  1. start (number). 0-based offset of the first selected character, or the
     cursor position when nothing is selected.
  2. stop (number). 0-based offset after the last selected character, or equal
     to start when nothing is selected.

When no text is selected, start and stop are equal, representing the cursor
position. When text is selected, start < stop, and the selected characters are
those at offsets start through stop - 1.

Returns nil if the current Automation host does not have a readable subtitle
edit box cursor.

---

Moving the subtitle edit box cursor

function aegisub.set_edit_box_cursor(...)

Requests the text cursor or selection to be changed in the main subtitle
text edit box when the current macro finishes. This also focuses the edit box.

The second parameter's type determines the mode:
  - set_edit_box_cursor(character_index, after)
    Legacy cursor mode. character_index is a 1-based character index. after is a
    boolean: false places the cursor before character_index, true after it.
    Values outside the current line are clamped.
  - set_edit_box_cursor(start, stop)
    Selection mode. Both start and stop are 0-based character offsets defining a
    half-open range [start, stop). When start == stop, the cursor is moved to
    that offset with no selection.
  - set_edit_box_cursor(character_index)
    Cursor mode with after=false.

Returns: 1 value, boolean.
  true if the request can be applied in the current Automation host, false
  otherwise.
