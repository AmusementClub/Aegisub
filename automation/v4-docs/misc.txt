Miscellaneous functions in Automation 4

This document describes various functions that couldn't be placed in any of
the other Automation 4 documents.

---

Getting the rendered size of a string

This function might later on be part of a full rendering-interface for
creating actual bitmaps of text.

This function does NOT attempt to handle line breaks, automatic line breaking,
fomatting override tags, vector drawings or anything else to that effect.
If you need such functionality, you need to implement it yourself. (For now,
at least.)

function aegisub.text_extents(style, text)

@style (table)
  A "style" class Subtitle Line table.

@text (string)
  The text to calculate the rendered size of.

Returns: 4 values, all numbers.
  1. Width of text in pixels.
  2. Height of text in pixels.
  3. Descent of text in pixels.
  4. External leading of text in pixels.

Focusing the subtitle edit box

function aegisub.focus_edit_box()

Requests keyboard focus for the main subtitle text edit box when the current
macro finishes.

Returns: 1 value, boolean.
  true if the request can be applied in the current Automation host, false
  otherwise.

Getting the subtitle edit box cursor

function aegisub.get_edit_box_cursor()

Returns the current cursor/selection position in the main subtitle text edit
box as a half-open range [start, stop) of 0-based character offsets.

Returns: 2 values.
  1. start (number). 0-based offset of the first selected character, or the
     cursor position when nothing is selected.
  2. stop (number). 0-based offset after the last selected character, or equal
     to start when nothing is selected.

When no text is selected, start and stop are equal, representing the cursor
position. When text is selected, start < stop, and the selected characters are
those at offsets start through stop - 1.

Returns nil if the current Automation host does not have a readable subtitle
edit box cursor.

---

Moving the subtitle edit box cursor

function aegisub.set_edit_box_cursor(...)

Requests the text cursor or selection to be changed in the main subtitle
text edit box when the current macro finishes. This also focuses the edit box.

The second parameter's type determines the mode:
  - set_edit_box_cursor(character_index, after)
    Legacy cursor mode. character_index is a 1-based character index. after is a
    boolean: false places the cursor before character_index, true after it.
    Values outside the current line are clamped.
  - set_edit_box_cursor(start, stop)
    Selection mode. Both start and stop are 0-based character offsets defining a
    half-open range [start, stop). When start == stop, the cursor is moved to
    that offset with no selection.
  - set_edit_box_cursor(character_index)
    Cursor mode with after=false.

Returns: 1 value, boolean.
  true if the request can be applied in the current Automation host, false
  otherwise.
